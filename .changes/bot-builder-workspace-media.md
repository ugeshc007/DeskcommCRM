- The flow workspace supports block search, duplicate, undo/redo, confirmed draft deletion and readable save feedback.
- Private image, multiple-image, MP4, audio and PDF blocks use organization-owned uploads and the existing guarded, idempotent delivery path. Empty uploads cannot be published. Interactive product carousels are not part of this increment.
